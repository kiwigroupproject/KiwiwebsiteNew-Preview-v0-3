# KiWi Technologies Website

Static site (HTML, CSS, vanilla JS), same approach as saamarthproperties.com and mahendrafacility.com. The HTML pages are generated by a small Node script so the header, footer and repeating page types live in one place.

## Run locally

Open `index.html`, or for a local server:

    cd D:\Claude\KiwiNewWebsite
    npx serve .

## Edit content, then rebuild

    node build.js        # regenerates every .html file (28 pages) and sitemap.xml

Do not edit the generated `.html` files by hand; changes are overwritten by the next build.

| To change | Edit |
|---|---|
| Home page sections | `src/home.html` |
| Services, case studies, blog posts (text, results, FAQs) | `src/data.js` |
| Header, footer, nav, About, Contact, Services overview, Work/Blog listings, legal text | `build.js` |
| Colours, fonts, layout | `css/styles.css` (tokens at top) |
| WhatsApp number, email, form endpoint | `CONFIG` at top of `js/script.js` |

## Pages

    index.html            Home
    about.html            Who We Are (story, values, timeline, team)
    services.html         Overview + engagement models
    services/*.html       8 service pages (generated from data.js)
    work.html             Portfolio with filter
    work/*.html           5 case studies
    blog.html             Insights listing with filter
    blog/*.html           6 articles
    contact.html          Enquiry form, details, next steps, FAQ
    privacy.html, terms.html, 404.html
